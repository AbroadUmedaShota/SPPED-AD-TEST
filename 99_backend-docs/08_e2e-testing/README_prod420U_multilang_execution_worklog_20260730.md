## 3. バックエンド調査結果（2026-07-29 19:21）との整合

先方の実装説明「候補は既定言語＋選択言語の2つ／候補が1つならOCRを見ずに確定／候補が複数なら住所付近をスコアリングし60以上で採用／未達は判定不能」は、実測400件と矛盾なく一致した。

- 日本語選択の247件が全件「日本語」→ 候補1言語でOCRを見ない挙動と一致
- 繁体字名刺が English/简体中文 選択時に「日本語」になる → 繁体字が候補外で漢字が日本語側に寄る
- 住所だけで結果が反転 → スコアリング対象が住所である説明と一致

グループ = 入力するフィールド種別。G1（メールアドレス）を入力すると G2 以降へ流れる。確定は OCR を含む3者中2票一致。

- 4アカウント（Lv4-02〜05）を並列で実行し、G1〜G6 が0件になるまで繰り返す
