## 3. 判明した事実・気づき

1. **多言語OFFの回答画面に言語プルダウンは無い**（回答言語はjaに固定）。SELECTS=0で実証。
2. **DLモーダルに言語フィルタが無い**。420（多言語ON）にはあった「すべての言語／中国語（簡体字）／日本語／英語」フィルタが、423では出ず「期間（全て/期間指定）」のみ。多言語OFFでは言語絞り込みが存在しない（＝全件日本語なので不要）。
3. **判定はデータ化入力を経ずに送信時点で自動付与**（未入力のまま回答データCSLに判定値が入る）。2026-07-15の420観測と一貫。
4. 送信は全件「通常回答」計上（テスト回答扱いではない）。**423に8件の実回答が残るためクリーンアップ要**（下記6）。
5. 名刺ファイル名は `0022200423_{回答ID}_1.jpg`（回答IDキー命名・裏面は空＝表面のみ送信）。

## 4. 解釈と限界（重要・正直な評価）

- 本結果は**本命仮説A（回答ja固定→日本語絡み→全件日本語判定・判定不能ゼロ＝安全）を支持**。420Mで問題視した「判定不能→納品漏れ」は、少なくとも多言語OFFの日本語運用では**発生しない**。
- ただし本テストは**仮説A（判定ルールが回答言語jaを見て日本語に寄せた）と仮説B（多言語OFFでは名刺言語判定が走らずアンケート言語=日本語を機械的に付与）を区別できない**。どちらでも出力は「日本語」で、実運用上の安全性の結論は同じ。区別するには**424-426（多言語ON）で同一の ja回答×外国語名刺 を送り、判定値が変わるか**を突き合わせる必要がある（判定エンジンが名刺画像を実際に見ているかの確認）。
- 名刺画像そのものの判定内訳（OCR結果）は本テスト範囲外（DL課金・データ化入力を伴うため）。

## 7.5 名刺データ振分（ルーティング）の実測 — 複数アカウント確認（2026-07-16 追記）

判定軸に続き、管理側で「日本語判定レコードが正しいオペレーターへ振り分けられるか」を複数アカウントで確認した。

### 振分結果（本命の確認事項）

- **データ化入力キューは全アンケート横断のグローバルキューだが、本テスト時点で他アンケートの滞留は0**（G1=8＝本テストの8件のみ、G2〜G8=0）。安全に検証できた。
- **同一の8件（すべて日本語判定）を4アカウントで確認**した作業可能件数（G1）:

| アカウント | 権限 | G1作業可能件数 |
|---|---|---|
| abroadcrew02 | Lv4 | 8 |
| abroadcrew03 | Lv3 | 8 |
| abroadcrew04 | Lv2 | **0** |
| abroadcrew05 | Lv1 | **0** |

→ **日本語判定レコードは日本語対応アカウント(02/03)にのみ出現し、非対応(04/05)には一切出ない**。対応可能言語による振分が効いていることを実証。420実走時の「日本語を外したアカウントには日本語判定の作業が来ない」と整合。

- **含意**: 423では外国語名刺(英/簡/繁)もすべて日本語判定のため、**全件が日本語対応オペレーターに集約され、中国語対応オペレーター(チームB=orange/チームC=西安)には一切振り分けられない**。日本語アンケートでは中国語名刺が中国語オペに回らない、という振分の実態が確認された。滞留・納品漏れは発生しない（判定不能0のため）が、外国語名刺を日本語オペが入力する運用になる点はデータ化品質の論点。
- オペレーター母集団: チームA=Abroad系(日本語想定)・B=orangeglobal.cn(中国語)・C=西安/data-bpo(中国語)。abroadcrew02-05は管理/入力アカウント（operator_listのオペレーターとは別レイヤ、operator名 "ab_Jonishi_test01" 等）。

### データ化入力（残留データ回避目的で完走）

- 8レコードを G1(メール)〜G6(URL) まで 02/03 の2アカウントで入力。**入力キューは全グループ0件までドレイン**。確定は「OCR＋人間1」で成立する項目（メール/URL/英字社名等）と「人間2」を要する項目が混在。
- 照合結果（最終）: 総件数8・**一致5・不一致2・未入力2**。不一致/未入力の残りは**CJK氏名・部署/役職のOCR誤読**（OCRが"="＝読取不能）に起因。氏名欄はOCR不能のまま確定され空になる挙動も観測（データ化品質の気づき）。※本テストの主目的（判定・振分の確認）は達成済みのため、照合の完全確定は未実施（ユーザー方針: 入力完成度は目的でない）。

## 7.55 商品仕様の確認：第1言語＝日本語固定（2026-07-16 追記）

- アンケート「新規作成」モーダルの入力欄は **アンケート名／表示タイトル／メモ／回答期間のみで、言語を選ぶ項目が存在しない**（作成画面スクショ evidence/c1_create.png）。→ ベース（第1）言語は日本語に固定で、作成時に他言語を選べない。
- 多言語は作成後の編集で「日本語ベースに en/zh を足す」アドオン。実データ5本すべて default_answer_locale=ja・supported_locales に ja 常在（Wiki61「未翻訳は第一言語＝日本語へフォールバック」と整合）。
- **含意**: 英語ベース・中国語ベースのアンケートは本商品では作成不能＝本番でテスト不能。「アンケート自体が英語/中国語のとき名刺がどう判定・振分されるか」は検証できない。観測可能な上限は「多言語アンケート(424-426)で回答言語プルダウンに en/zh を選んだ場合」まで（ベースは日本語のまま）。
