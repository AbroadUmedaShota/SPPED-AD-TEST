## 4. 本文に書く文章（固定・全言語で同一内容）

内容の違いが結果に影響しないよう、同じ意味の文を各言語で用意して使い回す。**英数字の識別子は本文に入れない**（文字種が判定に混ざるのを避けるため）。レコードの特定は回答IDの連番と送信順で行う。

- 日本語: 本日は展示会にて貴重なお話をありがとうございました。資料の送付をお願いいたします。
- 英語: Thank you for the valuable conversation at the exhibition today. Please send us the materials.
- 簡体字: 感谢您今天在展会上的宝贵交流。请向我们发送相关资料。
- 繁体字: 感謝您今天在展會上的寶貴交流。請向我們發送相關資料。

## 5. 使用する名刺（4言語 × 3枚 = 12枚）

昨日作成した各言語2枚（-01 / -02）に3枚目（-03）を追加して、各言語3枚を用意する。記載内容は同一言語内で共通とし、**メールアドレスとURLだけをカードごとに変える**（どの送信がどのレコードかを入力工程で特定できるようにするため）。実在の個人情報・企業情報は含まない。

| 言語 | カードID | 判別用の識別子 |
|---|---|---|
| 日本語 | R-JA-01 / -02 / -03 | r-ja-01〜03@example.com |
| 英語 | R-EN-01 / -02 / -03 | r-en-01〜03@example.com |
| 簡体字 | R-ZHHANS-01 / -02 / -03 | r-zhhans-01〜03@example.com |
| 繁体字 | R-ZHHANT-01 / -02 / -03 | r-zhhant-01〜03@example.com |

簡体字・繁体字は字形が異なる語（广告／廣告・质量／質量・电话／電話）を含めて画像だけで区別できるようにしてある。

## 6. 結果の見方

Phase 1（A軸）と Phase 2（B軸）を1セルずつ突き合わせる。

| 想定される結果 | 結論 |
|---|---|
| A軸とB軸で判定が同じ（16セル全部） | 設問の有無は判定に影響しない |
| B軸だけ「英語」「中国語」判定が出る | 設問（本文）の有無で判定が変わる → Phase 3で本文言語の寄与を確定 |
| C軸(443)がA軸と同じ | テキストの入力そのものが条件 |
| C軸がB軸と同じ | 回答行為の有無が条件 |

## 6.5 完了条件（必須）

1. 対象セルの判定値がすべて回収され、A軸／B軸／C軸の突き合わせ表が埋まっている
2. **データ化入力画面が、テスト用4アカウント（Lv4/Lv3/Lv2/Lv1）すべてでグループ1〜8とも作業可能件数0件になっている**（送信した名刺を入力画面に残さない。7/29と同じ手順で消化する）

## 7. 送信後の作業

- 判定値の回収: 対象アンケートごとに「回答データ」CSVを実ダウンロードし、「名刺の入力言語」「アンケートの回答言語」を目視確認（人間確認必須）
- **データ化入力のドレイン**: 437-443はオンデマンド設定のため、送信した117件が入力キューに乗る。昨日と同じ手順（1人目→2人目→必要なら3人目）で全アカウント0件まで消化する。**昨日は20件の消化に入力操作が計215回・約50分かかったため、117件では入力操作1,200回超・2時間前後を見込む**（自動実行のため待ち時間が主）。カードごとにメール／URLが異なるので、送信時に記録する「回答ID ↔ カードID」の対応表を使って入力値を出し分ける
- 振り分け先の観測は今回のスコープ外（オペレーターの対応可能言語は変更しない）。英語・中国語判定が出た場合は、別途言語分離した状態での観測を追加する
