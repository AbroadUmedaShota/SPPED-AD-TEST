## 2. 検証方法

- 作成: ダッシュボード→アンケート新規作成モーダル（アンケート名/表示タイトル/メモ/回答期間）→作成する。回答期間はflatpickr実クリック（月ドロップダウン→7月30日→8月29日）
- 設定: /survey/{id} 編集画面で多言語トグルON→言語チップ実クリック→設問追加（タイプは`select.question-type-select`で変更）→アンケート保存→確認モーダル「実行」
- データ化プラン: /survey/{id}/bizcard-settings（編集画面の「名刺データ化設定」ピルのリンク先）でオンデマンド行クリック→見込み枚数30→「設定を保存して依頼を確定する」
- 検証: 全本を再読込し、多言語トグル/チップ選択状態/設問タイプ・設問文/プラン選択/見込み枚数をDOMから読み戻し（final_summary.json）。スクショ証跡はセッションscratchpad `ml2/evidence/`

## 3. 作成過程で判明したUI仕様（発見）

1. **会期は最大31日間**: 作成モーダルで7/30〜8/30（32日間）を指定すると alert「会期は最大31日間です。」で拒否される。1ヶ月超の展示会・長期アンケートは作成不能ということ（仕様意図は未確認）
2. **対応言語は「日本語の他に最大2言語まで」**（多言語ONで注記表示・3つ目のチップはグレーアウト）。424-426がペア構成だったのはこの上限が理由と確定。全言語同時のアンケートは作れない
3. **対応言語の選択肢は English/中国語（簡体字）/中国語（繁体字）の3つのみ**。ベトナム語は本番の対応言語に未提供（SPDAD2026-90でDEVにベトナム語バリデーションメッセージが入っているが、ユーザー側の対応言語選択には来ていない）
4. **名刺データ化設定は編集画面内ではなく独立ページ** `/survey/{id}/bizcard-settings`（編集画面の「追加設定」ピルはリンク）。未保存編集があると離脱確認モーダル（confirmLeaveModal）が出る。プランは5種（お試し/通常/特急/超特急/オンデマンド）で項目数・納期・料金が異なる（お試しのみ2項目、他は10項目。納期は6営業日〜当日中。料金情報は共有境界ルール§3によりprivate管理のため本書に記載しない）。**プラン選択と見込み枚数は必須**（見込み枚数の初期値は100）
5. アンケート保存は確認モーダル（「アンケートを保存します。よろしいですか？」→実行）を挟む。ネイティブconfirmではなくカスタムモーダル
6. 新規作成モーダルに言語・プラン項目は無い（423 §7.55の「第1言語=日本語固定」と整合。プランは作成後にbizcard-settingsで設定する構造）
