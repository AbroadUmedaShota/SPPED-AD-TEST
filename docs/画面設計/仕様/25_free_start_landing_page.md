# 無料利用開始LP 仕様

## 1. 概要

`lp/free-start/index.html` は、SPEED ADの導入ハードルの低さを訴求し、既存の新規アカウント作成導線へ接続するキャンペーンLPである。

## 2. 訴求方針

- ファーストビューで `初期費用0円`、`月額基本料0円`、`御礼メール100通まで無料` を提示する。
- 「安い」だけでなく、QRアンケート、名刺データ化、御礼メールまでを一連で試せる価値を示す。
- 有料となる名刺データ化については、速度・入力項目に応じて料金が発生することを明記する。
- `無料アカウントを作成` はルートの `?intent=signup#top` に接続し、既存の登録モーダルを利用する。

## 3. ページ構成

1. ヘッダー・ファーストビュー
2. 無料で始めやすい3つの理由
3. 登録から回答受付までの3ステップ
4. 無料で試せる機能一覧
5. よくある質問
6. 最終CTA・フッター

## 4. 遷移先

- 無料アカウント作成: `../../?intent=signup#top`
- 料金プラン: `https://support.speed-ad.com/plans/`
- 利用規約: `https://support.speed-ad.com/terms/`
- プライバシーポリシー: `https://support.speed-ad.com/privacy/`
- ログイン: `../../#top`

## 5. 受入条件

- 1440px、768px、390px幅で主要テキストとCTAが重ならない。
- モバイルではメニューを開閉でき、リンク選択後に閉じる。
- FAQはキーボード操作で開閉できる。
- 登録CTAがルートの新規登録モーダルへ接続する。
- 外部の料金・規約ページは新規タブで開く。
- コンソールエラーが発生しない。

## 6. タイポグラフィ

- ブランド名 `SPEED AD` は公開ログイン画面と同じ `Noto Serif JP`（600）を使用する。
- 日本語本文とUIラベルは `Noto Sans JP`、英数字中心の補助表記は `Inter` を使用する。
- ブランド名の字間は `0.12em` を基準とし、斜体にはしない。
