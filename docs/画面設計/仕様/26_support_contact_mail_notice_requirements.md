# お問い合わせメール確認アプリの公開案内

## 画面と導線

- `/contact-review/` は、SPEED AD お問い合わせメール確認アプリの運営主体、業務上の用途、Gmailの読取専用利用、対象利用者、問い合わせ先を説明する静的ページとする。
- 案内ページから `/privacy/#contact-review-data` と `/terms/` へ到達できる。プライバシー方針のGmail説明から案内ページへ戻れる。
- `/` から `/help/` への既存転送は維持する。共通サポートシェルと既存の法務ページ用スタイルを使う。
- 案内ページにGmail認可・アプリログイン・メール情報を入力する操作は置かない。

## 説明する範囲

- 運営主体はアブロードアウトソーシング株式会社。対象窓口は `customer@speed-ad.com`。
- 通常同期は対象期間の送受信メールを迷惑メール・ゴミ箱も含めて取得し、下書きを除く。同期時に本文を照合し、不確定なメールは照合待ちとする。
- 認証済みの `@abroad-o.com` 社員全員と公式窓口の利用者が、案件に関連するメール・照合待ちの本文、添付、確認記録を閲覧する。
- 本文は同期時と閲覧時、添付本体は閲覧時に取得し、Firestoreへ保存しない。メールメタデータ、照合、確認記録、同期位置、監査・処理記録をFirestoreへ保存する。資格情報と同意記録はSecret Managerへ保存する。
- メール照合・確認記録は案件終了から3年、除外記録は除外確定から3年で削除する。Gmail原本が残る間、同期期間外でも再取込防止の最小メールID由来hashを保持する。
- 手動整理では期間外・下書き・迷惑メール・ゴミ箱を含む全GmailのIDを列挙し、一時hash集合を完了・取消しまでFirestoreへ保存する。整理のために期間外の本文・添付を取得しない。
- Gmailの送信・変更・削除権限を要求しない。新着だけで対応ステータスを変更しない。Google接続管理からの取消しと、記録削除の連絡先を案内する。

## 公開前の確認

現状のソースは未公開草案であり、案内ページとGmail説明に「公開前の確認用草案」を表示する。公開する文言・窓口・利用規約との整合が確定した後に、この表示を取り除く。既存の公開サイトへの反映とOAuth BrandingへのURL登録は、このソース作成とは別に実施する。

公開ホーム候補は `https://support.speed-ad.com/contact-review/`、プライバシーURL候補は `https://support.speed-ad.com/privacy/`。URL登録前にドメイン所有と公開ページの応答・内容を確認する。

## 受入条件

- 案内ページのアプリ名・運営法人・用途が読め、個人情報保護方針と利用規約へ到達できる。
- プライバシー方針のGmail説明に、通常同期と整理時の範囲の違い、閲覧者、保存内容・期間、停止・削除依頼が記載される。
- 新規ページとプライバシー方針で共通ヘッダー・フッター・既存画像・スタイルを読み込み、モバイル幅で横にはみ出さない。
- 草案の表示を外す前に公開文言を確認する。ソースの検証だけで本番公開・OAuth審査完了とは扱わない。
