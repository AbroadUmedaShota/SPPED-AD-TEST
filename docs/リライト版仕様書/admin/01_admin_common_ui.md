## 1. 文書目的

- 本書は、管理者画面の全画面に共通する画面骨格、一覧の操作規則、表記規則、出力規則を定義する。
- 画面別ファイルは本書を参照し、画面固有の要件のみを記載する。共通規則を各画面で再定義しない。
- 配色、フォント、コンポーネントの実装形式は本書の対象外とする。

## 2. 画面骨格

すべての管理者画面は次の 4 領域で構成する。

| 領域 | 内容 |
| --- | --- |
| ヘッダー | 画面上部に固定表示する。サービスロゴを配置する |
| サイドバー | 画面左に固定表示する。ログイン中アカウントのメールアドレスと権限表示、ナビゲーション、ログアウトを配置する |
| メインコンテンツ | パンくず、画面タイトル、画面固有の内容を配置する |
| フッター | 画面下部に配置する |

- 画面タイトルはメインコンテンツ上部に表示し、下部を区切り線で仕切る。
- パンくずは画面タイトルの上に表示し、階層をたどって上位画面へ戻れるようにする。
- 個票・作業画面（入力個票、照合個票）は、誤操作を防ぐためサイドバーを表示しない。離脱の導線は「一覧へ戻る」ボタンとする。主要領域は縦スクロールなしで 1 画面に収める。

参考: 現行モック `03_admin/common/sidebar.html` はヘッダー・サイドバー・フッターを共通パーツとして各画面に読み込んでいる。

## 3. サイドバーのナビゲーション

- ナビゲーションには、ログイン中アカウントがアクセスできる画面のみを表示する。表示条件は `00_admin_common_permissions.md` §3 に従う。
- ナビゲーション項目には画面名を表示する。現在表示中の画面の項目は選択状態として区別する。
- ナビゲーションの末尾にログアウトを配置する。

参考: 現行モック `03_admin/common/sidebar.html` のナビゲーションは、ダッシュボード／ユーザー管理／アンケート管理／請求管理／クーポン管理／営業日カレンダー管理／名刺入力一覧（モック上の表記は「データ入力一覧」）／照合管理一覧／オペレーター管理／実績管理の 10 項目である。操作ログ画面と請求書管理画面の項目は追加が必要となる。

## 4. 一覧画面の共通規則

一覧を持つ画面は、次の規則を共通で満たす。

### 4.1 検索と絞り込み

- 検索条件の入力欄と絞り込み条件の選択欄は、一覧の上部にまとめて配置する。
- 検索条件は画面ごとに定める。複数の検索キーを 1 つの入力欄でまとめて扱う場合は、対象とするキーをプレースホルダに明示する。
- 絞り込み条件は選択式とし、初期値は「すべて」とする。
- 条件をまとめて初期状態へ戻す操作を用意する。
- 条件を変更した結果、該当が 0 件の場合は、一覧の位置に該当なしの旨を表示する。

### 4.2 並び替え

- 並び替えを提供する列は、列見出しの押下で昇順・降順を切り替える。
- 現在の並び替え対象列と方向は、列見出し上で判別できるようにする。

### 4.3 ページング

- 一覧は既定で 1 ページあたり 10 件を表示する。表示件数は 10 件・25 件・50 件から選択できる。
- ページ番号、前ページ、次ページの操作を一覧の下部に配置する。
- 全体件数と現在の表示範囲を数値で表示する。

参考: 現行モック `03_admin/reconciliation/index.html` は表示件数 10 / 25 / 50 の選択とページ番号操作を備える。

### 4.4 読込中と取得失敗の表示状態

一覧と集計領域は、データの取得状況に応じて次の表示状態を持つ。モックアップでは各状態を表示状態として作成する。

| 状態 | 表示 |
| --- | --- |
| 初回読込中 | 一覧・集計領域の位置に読込中である旨を表示する。検索・絞り込み・並び替え・ページングの操作は受け付けない |
| 再読込中 | 直前に表示していた内容を維持したまま、読込中である旨を示す |
| 取得失敗 | 取得に失敗した旨と再試行の操作を表示する。直前に表示していた内容がある場合は維持する |
| 集計のみ失敗 | 一覧は取得した内容を表示し、集計領域にのみ取得に失敗した旨と再試行の操作を表示する |

- 該当が 0 件の状態（§4.1）と取得失敗の状態は、表示上で区別する。
- 再試行の操作は、失敗した領域の内側に配置する。

## 5. 集計値の表示

- 集計値は数値カードまたは表として表示する。カードには項目名と数値を配置する。補足文を添えるかどうかと、その内容は画面別ファイルで定める。
- 進捗は「完了件数 / 総件数」の形式で数値表示し、併せて百分率を整数で表示する。
- 集計対象の範囲は、ログイン中アカウントのデータ範囲に従う（`00_admin_common_permissions.md` §5）。
- 集計値の反映には遅延を許容する（`05_admin_nonfunctional.md` §2）。画面には集計の最終更新日時を表示する。
- 集計値の取得中および取得に失敗した場合の表示は §4.4 に従う。

## 6. 詳細表示とモーダル

- 一覧から個別レコードの詳細を開く場合は、モーダルまたは詳細画面のいずれかとする。どちらを用いるかは画面別ファイルで定める。
- モーダルは背景をオーバーレイで覆い、閉じる操作を右上と画面外クリックの両方で提供する。
- モーダル内で編集を行った場合、閉じた後の一覧は更新後の値を表示する。
- 作業画面（入力個票、照合個票）はモーダルとせず、独立した画面とする。

## 7. 操作の確認と実行

### 7.1 確認ダイアログ

次に該当する操作は、実行前に確認ダイアログを表示する。ダイアログには対象の識別子（アンケート ID、ユーザー ID、アカウント名など）を明示する。

- データを削除する操作
- アカウントを無効化する操作
- 公開後のアンケートに対する変更
- 完了データの手動アップロード
- パスワードの管理者直接設定
- 請求金額・契約状態に影響する変更（入金情報の変更、プレミアム契約状態の変更、クーポンの事後適用）

### 7.2 理由の入力

パスワードの管理者直接設定は、確認ダイアログ内で理由の入力を必須とする。入力した理由は監査ログに記録する（`02_admin_common_audit_log.md`）。

### 7.3 実行中の制御

- 実行ボタンは押下後に非活性化し、二重実行を防ぐ。
- 実行結果は画面上部に成功または失敗のメッセージとして表示する。失敗時は入力内容を保持する。

## 8. 入力フォームの共通規則

- 必須項目にはラベル横に必須の表示を付ける。
- 入力エラーは該当欄の直下にメッセージを表示する。複数欄でエラーが発生した場合は、最初のエラー欄へフォーカスを移す。
- 保存せずに画面を離れようとした場合、入力内容がある間は確認ダイアログを表示する。
- 選択肢が DB マスタ由来の項目（対応可能言語など）は、マスタの登録内容から選択させる。

## 9. 表記規則

| 対象 | 表記 |
| --- | --- |
| 日付 | `YYYY/MM/DD` |
| 日時 | `YYYY/MM/DD HH:MM` |
| 件数 | 半角数字。3 桁ごとにカンマ区切り |
| 金額 | 半角数字。3 桁ごとにカンマ区切り。単位は「円」 |
| 割合 | 整数の百分率。単位は「%」 |
| 該当なし | 「—」 |

- 時刻は日本標準時（JST）で表示する。
- 納期など期限を持つ日時は、日付だけでなく時刻まで表示する。

## 10. ファイル出力

- CSV 出力を持つ画面は、出力操作を一覧の上部または集計領域に配置する。
- 出力対象は、その時点で適用されている検索条件・絞り込み条件の結果とする。ページングの表示範囲には限定しない。
- 文字コードは UTF-8（BOM 付き）とし、改行コードは CRLF とする。
- ファイル名には画面名と出力日時を含める。
- CSV および名刺画像の出力は監査ログの記録対象とする（`02_admin_common_audit_log.md`）。

## 11. 対応環境

対応ブラウザ、画面幅、アクセシビリティの扱いは `05_admin_nonfunctional.md` に従う。

## 12. 画面外の確認事項

| # | 項目 | 内容 |
| --- | --- | --- |
| 1 | 一覧の取得方式 | ページングをサーバー側で行うか画面側で行うかを確定する。件数が大きい画面（アンケート管理、名刺入力）ではサーバー側での絞り込みを前提とする。 |
| 2 | 集計の更新間隔 | 集計値の再計算タイミングと、画面に表示する最終更新日時の取得元を確定する。 |
| 3 | CSV の文字コード | UTF-8（BOM 付き）で表計算ソフトの想定利用に耐えるかを確認する。Shift_JIS の要望がある場合は出力時の選択可否を決める。 |
| 4 | 出力ファイルの保管 | CSV・名刺画像のダウンロードで生成するファイルをサーバー側に保管するか、都度生成するかを確定する。 |
| 5 | 詳細のモーダル採用範囲 | 実績個別詳細をモーダルとするか独立画面とするかを確定する（`24_admin_achievements.md` §11 の #8）。ユーザー詳細（SCR-A-003）とアンケート詳細（SCR-A-005）は独立画面として確定済みであり、本項の対象外とする。 |
| 6 | セッションタイムアウト | 無操作時のセッション有効時間と、作業画面（入力個票・照合個票）での延長方針を確定する。 |
| 7 | 一覧の同時更新 | 複数の管理者が同一データを同時に更新した場合の扱い（後勝ち／排他制御）を確定する。 |
