# オペレーター実績確認 要件定義書

| 項目 | 値 |
| --- | --- |
| 対象画面 | `/admin/achievements` |
| 画面 ID | SCR-A-015 |
| 正本区分 | 本書を正本とする |
| owner | product |

## 1. 文書目的

- 本書は、オペレーター実績確認（オペレーターの作業量と品質の集計）の要件を定義する。
- 全画面に共通する権限、UI 規則、監査ログ、通知、用語は共通編を参照する。本書は本画面に固有の要件を扱う。
- オペレーターアカウントの登録・権限設定は本書の対象外とし、`23_admin_operator_management.md` で扱う。

## 2. 画面概要

- オペレーターの作業量と品質を、報酬と評価の根拠になる形で集計して表示する画面。
- 表示は集計表と数値で構成する。グラフは使わない。
- 一覧はグループ別集計とオペレーター別集計の 2 タブで切り替える。月単位で対象期間を切り替える。
- 一覧の行を選択すると、グループ実績詳細（§4.8）またはオペレーター実績詳細（§4.9）へ遷移する。作業グループ①〜⑧・入力項目別・日別の内訳は詳細側で表示する。
- 集計結果は CSV として出力する。

## 3. 想定利用者と対象範囲

### 3.1 想定利用者

- 作業を管理する Lv2（OperatorAdmin）。自グループのオペレーターの作業量と品質を確認する。
- 運営全体を管理する Lv3・Lv4。全グループの実績を確認し、報酬と評価の根拠として用いる。

### 3.2 対象範囲

- グループ別の集計表示（タブ①）
- チーム別の集計表示（※要確定）
- オペレーター別の集計表示（タブ②）
- グループ実績詳細（月次推移・作業グループ別内訳・所属オペレーター）
- オペレーター実績詳細（月次推移・作業グループ×入力項目別内訳・日別実績）
- 月単位での期間切り替え
- CSV 出力

### 3.3 対象外

- オペレーターアカウントの登録・編集・権限設定（`23_admin_operator_management.md`）
- 作業の割り当てとアサイン（`18_admin_calendar.md`、`19_admin_data_input_list.md`）
- 入力・照合の作業そのもの（`20_admin_data_input_form.md`、`22_admin_matching_form.md`）

## 4. 画面要件

### 4.1 共通構成

- ヘッダー、サイドバー、パンくずを表示する（`01_admin_common_ui.md` §2）。
- 画面タイトルを表示する。
- 画面は上から、期間と絞り込みの条件、タブ（グループ別集計・オペレーター別集計）、選択中タブの集計表の順に配置する。
- 集計は表と数値で表示する。

### 4.2 集計条件

| 条件 | 種別 | 内容 |
| --- | --- | --- |
| 対象期間 | 選択 | 年月を指定する。初期値は当月 |
| 所属グループ | 絞り込み | 登録済みのグループから選択する。初期値は「すべて」 |

条件を変更すると、各集計表を再取得して表示する。

オペレーター管理（SCR-A-014）から遷移した場合は、対象のオペレーターで絞り込んだ状態で開く（`01_admin_common_ui.md` §4.1.1）。受け取る条件はオペレーター ID・氏名とし、オペレーター別集計（§4.5）に適用する。

### 4.3 集計指標

各集計表で扱う指標は次のとおりとする。

| 指標 | 内容 |
| --- | --- |
| 作業件数 | 対象期間中に処理した件数 |
| 正解件数 | 処理のうち正解と判定された件数 |
| 正答率 | 作業件数に対する正解件数の割合 |
| スキップ回数 | スキップを実行した回数 |
| 報酬金額 | 作業件数と単価から算出する金額（※要確定） |

- 件数と回数は 3 桁ごとのカンマ区切りで表示する。正答率は整数の百分率で表示する（`01_admin_common_ui.md` §9）。
- 正解件数と正答率の判定定義は §11 で確定する。照合の一致・不一致判定と同一の定義を用いる。
- 報酬金額を本画面に含めるかは確定前とする（※要確定・§11）。

### 4.4 グループ別集計

グループごとに次を表示する。

| 表示項目 | 内容 |
| --- | --- |
| グループ名 | 集計対象のグループ |
| 合計作業件数 | グループ内の作業件数の合計 |
| 合計正解件数 | グループ内の正解件数の合計 |
| 平均正答率 | グループ内の正答率の平均 |
| 合計スキップ回数 | グループ内のスキップ回数の合計 |
| 合計報酬金額 | グループ内の報酬金額の合計（※要確定） |
| 最終報酬金額 | 現行画面が持つ調整後の報酬金額。合計報酬金額との差の定義は確定前（※要確定・§11 の #4） |

- 行を選択すると、そのグループのグループ実績詳細（§4.8）へ遷移する。
- 平均正答率の算出方法（オペレーター別正答率の単純平均か、合計正解件数を合計作業件数で割った値か）は §11 で確定する。
- グループ別集計に加えて、チーム単位の集計を同じ指標で表示する。現行画面はチーム A / B / C 単位で所属を管理しており、会社・法人単位のグループへ移行した後もチームを集計軸として残す前提とする。移行後の位置づけは §11 の #6 で確定する（※要確定）。

### 4.5 オペレーター別集計

オペレーターごとに次を表示する。

| 表示項目 | 内容 |
| --- | --- |
| オペレーター ID | 対象のオペレーター |
| 氏名 | 対象の氏名 |
| 所属グループ | 所属する会社・法人 |
| 作業件数 | 対象期間中の作業件数 |
| 正解件数 | 対象期間中の正解件数 |
| 正答率 | 作業件数に対する正解件数の割合 |
| スキップ回数 | 対象期間中のスキップ回数 |
| 報酬金額 | 対象期間中の報酬金額（※要確定） |

オペレーター別集計は表形式とし、行をオペレーター、列を §4.3 の指標とする。一覧にはオペレーターごとの合計行のみを表示する。

- 行を選択すると、そのオペレーターのオペレーター実績詳細（§4.9）へ遷移する。作業グループ①〜⑧・入力項目別の内訳は詳細側で表示する（2026-08-12 に一覧内の 2 段階展開から移設）。
- 一覧はページングと表示件数の選択に対応する（`01_admin_common_ui.md` §4.3）。
- 各列で昇順・降順の並び替えができる。

### 4.6 CSV 出力

- 開いているタブの集計表を CSV として出力する。
- 出力対象は、その時点で適用されている期間と絞り込み条件の結果とする。
- 出力形式と文字コードは `01_admin_common_ui.md` §10 に従う。
- 出力は監査ログの記録対象（データ持ち出し）とする（`02_admin_common_audit_log.md` §3）。

### 4.7 個別詳細の導入（2026-08-12 確定）

個別詳細は独立画面として導入する（モーダルは採らない・§11 の #8）。グループ 1 件のグループ実績詳細（§4.8）と、オペレーター 1 名のオペレーター実績詳細（§4.9）の 2 画面とする。運営側（Lv3・Lv4）は委託先の品質と支払額の確認に、委託側（Lv2）は自グループの成績と報酬根拠の確認に用いる。

### 4.8 グループ実績詳細（新設・画面 ID 未採番 ※要確定）

`?group=<グループID>` で対象を受け取る。画面は上から次の順に配置する。

| ブロック | 内容 |
| --- | --- |
| サマリ数値カード | 対象期間の作業件数・正解件数・正答率・スキップ回数・合計報酬金額・最終報酬金額・稼働人数 |
| 月次推移 | 直近 6 ヶ月の表（§4.3 の指標＋合計報酬金額・最終報酬金額）。表示中の月の行を強調する |
| 作業グループ①〜⑧別の内訳 | グループ内の合算。正答率がもっとも低い作業グループを注記する |
| 所属オペレーター一覧 | §4.3 の指標付き。行を選択するとオペレーター実績詳細（§4.9）へ遷移する |

- 対象期間の切り替えは一覧（§4.2）と同じ月単位とする。
- 報酬金額の算出根拠（単価 × 作業件数）を画面下部に注記する。

### 4.9 オペレーター実績詳細（新設・画面 ID 未採番 ※要確定）

`?oid=<オペレーターID>` で対象を受け取る。画面は上から次の順に配置する。

| ブロック | 内容 |
| --- | --- |
| サマリ数値カード | 対象期間の作業件数・正解件数・正答率・スキップ回数・報酬金額。報酬の算出根拠（単価 × 作業件数）を注記する |
| 月次推移 | 直近 6 ヶ月の表。表示中の月の行を強調する |
| 作業グループ①〜⑧×入力項目別の内訳 | 作業グループ行の選択で入力項目ごとの内訳を展開する。作業グループと入力項目は `20_admin_data_input_form.md` §4.4 の項目表に従う |
| 日別実績 | 稼働日ごとの作業件数・正解件数・正答率・スキップ回数 |

- 氏名・オペレーター ID・所属グループを画面上部に表示する。所属グループはグループ実績詳細（§4.8）への導線とする。
- 対象期間の切り替えは一覧（§4.2）と同じ月単位とする。

## 5. 通知

本画面の操作を起点とする通知・メールの発火はない（`03_admin_common_notifications.md` §2）。

## 6. 権限とデータ範囲

| 権限レベル | 扱い |
| --- | --- |
| Lv1 | 本画面へアクセスできない（§11 で確定） |
| Lv2 | 自グループのオペレーターの実績のみを表示できる |
| Lv3 | 全グループの実績を表示できる |
| Lv4 | 全グループの実績を表示できる |

- 権限判定とデータ範囲の絞り込みはサーバー側で行う（`00_admin_common_permissions.md` §9.1）。
- グループ実績詳細（§4.8）・オペレーター実績詳細（§4.9）も本画面と同じ権限・データ範囲に従う。Lv2 が表示できるのは自グループと配下オペレーターの詳細のみとする。
- Lv1 本人に自分の実績の閲覧を許可するかは確定前とする（※要確定・§11）。

## 7. 状態と挙動

### 7.1 初期表示

- 対象期間は当月、所属グループの絞り込みは「すべて」、タブはグループ別集計を選択した状態で表示する。
- オペレーター管理から `?oid=` 付きで遷移した場合は、オペレーター別集計のタブを選択した状態で表示する。

### 7.2 集計値の反映

- 集計値は最大 5 分の反映遅延を許容する（`05_admin_nonfunctional.md` §2）。
- 画面には集計の最終更新日時を表示する。

### 7.3 対象期間の切り替え

- 対象期間を切り替えると、各集計表を再取得する。
- 作業実績が存在しない期間では、各集計表に該当なしの旨を表示する。

### 7.4 集計対象

- 集計対象は入力作業の実績とする。照合作業を集計対象に含めるかは §11 の #7 で確定する。
- 無効にしたオペレーターの過去の実績は集計に含める。

## 8. 現行画面からの引き継ぎ

現行画面 `/admin/achievements` は次を備える。本画面はこれらの機能を引き継ぐ最低線とする。

| 現行の機能 | 本書での扱い |
| --- | --- |
| 期間（月）のフィルタ | §4.2 |
| 所属グループのフィルタ（すべて／チーム A・B・C） | §4.2。グループは会社・法人単位へ移行する |
| グループ別集計（合計作業件数／合計正解件数／平均正答率／合計報酬金額／合計スキップ回数／最終報酬金額） | §4.4 |
| オペレーター別集計（作業グループ 1〜8 の項目別） | §4.5（合計行）・§4.9（項目別の内訳） |
| 表示中タブの CSV 出力 | §4.6 |

現行画面の「最終報酬金額」は、合計報酬金額との差を確認できていない。両者の関係は §11 で確定する。

参考: 現行モック `03_admin/performance-management.html` は、氏名・ID・所属グループの検索と、稼働状況・展示会・チーム・達成状況・品質区分・規模・評価区分による多段の絞り込みを持つ。絞り込みの区分は現行サービスと一致しない。モックは仕様上の正解とは扱わない。

## 10. 画面確認観点

モックアップ上で次を確認する。

- [ ] 対象期間を年月で切り替えられ、初期値が当月である
- [ ] 所属グループで絞り込める
- [ ] グループ別集計とオペレーター別集計をタブで切り替えられる
- [ ] グループ別集計に合計作業件数・合計正解件数・平均正答率・合計スキップ回数が表示される
- [ ] チーム別集計が同じ指標で表示される
- [ ] オペレーター別集計に作業件数・正解件数・正答率・スキップ回数が表示され、初期状態がオペレーターごとの合計行のみである
- [ ] グループ行を選択するとグループ実績詳細へ、オペレーター行を選択するとオペレーター実績詳細へ遷移する
- [ ] オペレーター管理から `?oid=` 付きで遷移すると、オペレーター別集計タブが対象で絞り込まれた状態で開く
- [ ] グループ実績詳細にサマリ数値カード・月次推移・作業グループ①〜⑧別内訳・所属オペレーター一覧が表示される
- [ ] オペレーター実績詳細にサマリ数値カード・月次推移・作業グループ×入力項目別内訳・日別実績が表示され、作業グループ行の選択で入力項目の内訳が開く
- [ ] オペレーター実績詳細の所属グループからグループ実績詳細へ遷移できる
- [ ] 件数と回数が 3 桁ごとのカンマ区切り、正答率が整数の百分率で表示される
- [ ] 開いているタブの集計表を CSV 出力でき、画面表示と同一の値が出力される
- [ ] 集計の最終更新日時が表示される
- [ ] 作業実績が存在しない期間で、各集計表に該当なしの旨が表示される
- [ ] Lv2 でログインした場合、他グループのオペレーターが集計に含まれない
- [ ] 無効にしたオペレーターの過去の実績が集計から欠落しない

## 11. 画面外の確認事項

| # | 項目 | 内容 |
| --- | --- | --- |
| 1 | 正解・正答率の判定定義 | 何をもって正解とみなすかを確定する。入力の確定条件（`20_admin_data_input_form.md` §11 の #2）、照合の一致・不一致判定（`22_admin_matching_form.md` §11 の #2）、照合結果一覧の完了件数（`21_admin_matching_list.md` §11 の #5）と併せて、本項を含む 4 点を同一の定義で確定する。定義が割れると、同じ作業に対して画面ごとに異なる件数が表示される。 |
| 2 | 正答率の分母 | 正答率の分母を作業件数とするか、照合で確定した件数に限るかを確定する。#1 と同時に決める。#1 に挙げた 4 点の定義に含まれる。 |
| 3 | 報酬金額の扱い | 報酬金額を本画面に含めるかを確定する。含める場合、単価の設定方法（項目別・グループ別）と算出式を決める。 |
| 4 | 合計報酬金額と最終報酬金額 | 現行画面が持つ 2 つの報酬金額の違いを確定する。控除や調整を反映した値が最終報酬金額かを確認する。 |
| 5 | Lv1 本人の閲覧 | Lv1 本人に自分の実績の閲覧を許可するかを確定する。許可する場合、表示する指標（報酬金額を含めるか）を決める。 |
| 6 | 集計軸としてのチーム | 現行のチーム A / B / C を、会社・法人単位のグループへ移行した後も集計軸として残すかを確定する。残す場合、グループとチームの階層関係を定義する。 |
| 7 | 集計対象の作業範囲 | 入力作業に加えて照合作業を集計対象に含めるかを確定する。含める場合、照合の正解件数をどう数えるかを決める。 |
| 8 | 個別詳細の形式 | 独立画面で確定（2026-08-12）。要件は §4.8・§4.9。画面 ID の採番のみ残る。 |
| 9 | 評価指標の追加 | 作業件数・正答率・スキップ回数以外に、評価の根拠とする指標があるかを確定する。 |
| 10 | 平均正答率の算出方法 | §4.4 の平均正答率を、オペレーター別正答率の単純平均とするか、合計正解件数を合計作業件数で割った値とするかを確定する。作業件数の偏りが大きいグループで両者の差が開く。 |
| 11 | 所属変更前の実績の集計先 | オペレーターの所属グループを変更した場合、変更前に行った作業の実績を旧グループと新グループのどちらへ集計するかを確定する。過去の期間を遡って集計し直すかを併せて決める。`23_admin_operator_management.md` §7.4 と連動する。 |
| 12 | オペレーター別集計の表示階層・展開方式 | 一覧は合計行のみとし、作業グループ①〜⑧×入力項目・日別の内訳はオペレーター実績詳細（§4.9）へ移設で確定（2026-08-12）。 |
