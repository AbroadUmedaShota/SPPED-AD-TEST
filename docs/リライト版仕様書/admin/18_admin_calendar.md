# 営業日カレンダー管理 要件定義書

| 項目 | 値 |
| --- | --- |
| 対象画面 | `/admin/calendar` |
| 画面 ID | SCR-A-008 |
| 正本区分 | 本書を正本とする |
| owner | product |
| last_reviewed | 2026-07-31 |

## 1. 文書目的

- 本書は、営業日カレンダー管理の要件を定義する。
- 全画面に共通する権限、UI 規則、監査ログ、通知、用語は共通編を参照する。本書は本画面に固有の要件を扱う。
- 納期日時そのものの表示と照合作業の進捗は本書の対象外とし、`21_admin_matching_list.md` で扱う。

## 2. 画面概要

- 納期計算の前提となる休業日と振替営業日を運営側で管理する画面。
- あわせて、Lv2 が案件量と人員を見比べて作業をアサインする運用画面として機能する。
- 月単位のカレンダーを中心に構成し、日付ごとの営業日設定、その日に会期を持つアンケート、作業のアサイン状況を扱う。
- 表示範囲と操作範囲はログイン中アカウントのデータ範囲と権限に従う（§6）。

### 2.1 アサインの責務分担

| 画面 | 担当する範囲 |
| --- | --- |
| 営業日カレンダー管理（本画面） | アサインの実行。日付とオペレーターの組み合わせを決め、案件量と人員の過不足を判断する |
| 名刺入力一覧（SCR-A-009） | 作業の実施。作業可能件数の確認と入力画面への遷移 |

アサイン結果を名刺入力一覧へどう反映するかは §7.3 で扱う。

## 3. 想定利用者と対象範囲

### 3.1 想定利用者

- 作業をアサインする Lv2（OperatorAdmin）。案件量と人員のバランスを見て、日ごとの作業割当を決める。
- 営業日を管理する Lv3・Lv4。休業日・振替営業日を設定し、納期計算の前提を維持する。

### 3.2 対象範囲

- 休業日・振替営業日の設定と変更
- 定休日（曜日単位）の設定
- 月次カレンダー上でのアンケート表示
- 作業のアサインとキャパシティの調整

### 3.3 対象外

- 納期日時の算出ロジック
- 入力・照合の作業進捗（`19_admin_data_input_list.md`、`21_admin_matching_list.md`）
- オペレーターの登録・権限設定（`23_admin_operator_management.md`）

## 4. 画面要件

### 4.1 共通構成

- ヘッダー、サイドバー、パンくず、フッターを表示する（`01_admin_common_ui.md` §2）。
- 画面タイトルを表示する。
- 月単位のカレンダーを中心に配置し、前月・翌月へ移動する操作を用意する。
- 月セルにはその日の会期件数とアサイン人数を併記し、表示の切り替えは設けない。両方を同時に読めるため、切り替える利点がないためである。

### 4.2 カレンダー表示

- 表示単位は月とする。1 日を 1 マスとして日付順に配置する。
- 各日付には次を表示する。

| 表示項目 | 内容 |
| --- | --- |
| 日付 | 年月日 |
| 営業日区分 | 営業日、休業日、振替営業日のいずれか |
| 会期中のアンケート件数 | その日に会期を持つアンケートの件数 |
| アサイン済み人数 | その日に作業をアサインしたオペレーターの人数 |

- 件数・人数は数値で表示する。
- 月セル内に個別のアンケートを列挙しない。アンケートに関する表示は会期中のアンケート件数に限る。
- 日付を選択すると、カレンダー下部の日付詳細領域に、その日の対象アンケートとアサイン状況を表示する（§4.4、§4.5）。
- 選択中の日付は、営業日区分の表示とは別に、選択状態としてカレンダー上で識別できるようにする。
- カレンダーには、休業日・振替営業日・選択中の各状態を示す凡例を添える。
- 月セルの表示方式は確定前とする（※要確定・§11 の #13）。

### 4.3 営業日の設定

| 設定 | 内容 |
| --- | --- |
| 定休日 | 曜日単位で休業日とする設定。土曜・日曜・祝日をそれぞれ指定する |
| 個別休業日 | 日付を指定して休業日とする設定 |
| 振替営業日 | 定休日にあたる日付を、営業日として扱う設定 |

- 設定の変更は Lv3 以上が行う（§6）。
- 個別休業日と振替営業日には、設定の理由をメモとして記録できる。
- 設定を削除する場合は確認ダイアログを表示する（`01_admin_common_ui.md` §7.1）。

同一の日付に複数の設定が及ぶ場合、次の規則で解決する。規則の全体は確定前とする（※要確定・§11 の #12）。

- 個別設定（個別休業日・振替営業日）を定休日・祝日より優先する。定休日・祝日と重なる日付では、個別設定の内容をカレンダー表示と納期計算に用いる。
- 同一の日付に個別休業日と振替営業日を重複して設定することはできない。重複する設定を保存しようとした場合はエラーを表示し、保存しない。

### 4.4 アンケート表示

- 月セルには、その日に会期を持つアンケートの件数を表示する（§4.2）。
- 日付を選択すると、カレンダー下部の日付詳細領域に、その日に会期を持つアンケートを一覧表示する。アンケートごとにアンケート ID、タイトル、納期日時を表示する。
- 日付詳細領域に収まらない件数がある場合は、領域内の縦スクロールで全件を確認できるようにする。
- 表示対象はログイン中アカウントのデータ範囲に限定する。
- 日付詳細領域の構成は確定前とする（※要確定・§11 の #13）。

日付詳細領域のアンケートごとに、作業画面への遷移導線を配置する。

| 遷移先 | 表示条件 | 引き継ぐ内容 |
| --- | --- | --- |
| 名刺入力一覧（SCR-A-009） | 対象アンケートに名刺データ化の対象が存在する場合に表示する | 選択中の日付と対象アンケート |
| 照合管理一覧（SCR-A-011 / SCR-A-012） | 対象アンケートに名刺データ化の対象が存在する場合に表示する | 選択中の日付と対象アンケート |

- 引き継いだ日付とアンケートは、遷移先の絞り込み条件へ適用した状態で表示する。

### 4.5 アサイン

- 日付とオペレーターの組み合わせで作業をアサインする。
- アサイン画面には、その日の案件量（会期中のアンケート件数、対象名刺の件数）とアサイン済み人数を並べて表示し、過不足を判断できるようにする。
- アサインを確定すると、対象のオペレーターへ割当通知を送信する（§5）。
- アサインの取り消しができる。

### 4.6 追加要件（あったほうが良い）

| 要件 | 内容 |
| --- | --- |
| 祝日・稼働可能日の CSV インポート | 祝日および稼働可能日を CSV ファイルから一括で取り込む |

## 5. 通知

- アサインを確定したとき、アサインされたオペレーターへ割当通知を送信する（`03_admin_common_notifications.md` §2 の #5）。
- 通知には対象の日付と作業内容を含める。
- 同一オペレーターへの複数のアサインが同時に確定した場合の送信単位は `03_admin_common_notifications.md` §8 の #2 で確定する。

## 6. 権限とデータ範囲

| 権限レベル | 扱い |
| --- | --- |
| Lv1 | 本画面へアクセスできない。サイドバーに項目を表示しない |
| Lv2 | 自グループのデータのみを表示・操作できる。操作はキャパシティ調整と作業アサインに限る |
| Lv3 | 全グループのデータを表示・操作できる。休業日・振替営業日の設定を含む全機能を利用できる |
| Lv4 | 全グループのデータを表示・操作できる。休業日・振替営業日の設定を含む全機能を利用できる |

- Lv2 に対しては、営業日設定の操作要素を表示しない（`00_admin_common_permissions.md` §6）。
- Lv2 は営業日設定の内容を参照できる。納期の前提となる休業日を把握したうえでアサインを判断するための規定であり、たたき台に対応する記載はない（※要確定・§11）。
- 権限判定とデータ範囲の絞り込みはサーバー側で行う（`00_admin_common_permissions.md` §9.1）。

## 7. 状態と挙動

### 7.1 初期表示

- 当月のカレンダーを表示する。

### 7.2 営業日設定の反映

- 営業日設定を変更すると、以降に算出する納期日時へ反映する。
- 既存案件の納期日時へ遡って反映するかは §11 で確定する。

### 7.3 アサインの反映

- アサインを確定すると、対象日のアサイン済み人数を更新する。
- アサイン結果を名刺入力一覧（SCR-A-009）へどう反映するかは §11 で確定する。出題対象そのものを制約するか、進捗把握のための記録に留めるかで、作業者側の挙動が変わる。

### 7.4 集計値の反映

- 会期中のアンケート件数と対象名刺の件数は、最大 5 分の反映遅延を許容する（`05_admin_nonfunctional.md` §2）。

## 8. 現行画面からの引き継ぎ

現行画面 `/admin/calendar` は次を備える。本画面はこれらの機能を引き継ぐ最低線とする。

| 現行の機能 | 本書での扱い |
| --- | --- |
| 定休日設定（土曜・日曜・祝日のチェック） | §4.3 |
| 個別休業日の設定 | §4.3 |

振替営業日の設定、アンケート表示、アサインは現行画面に存在しない。§4.3〜§4.5 は新規に追加する要件として扱う。

参考: 現行モック `03_admin/calendar-management.html` は 2026 年 6〜8 月の 3 か月を対象に、月移動、日付選択と日付詳細、アサインの追加・取り消し、個別休業日・振替営業日の追加（重複と振替妥当性の検証込み）と削除確認、定休日・祝日の設定、CSV インポート（§4.6）をページ内の状態で実装している。会期・納期のデータはアンケート管理・照合管理一覧と同一のものを用いる。モックは仕様上の正解とは扱わない。

## 10. 画面確認観点

モックアップ上で次を確認する。

- [ ] 月単位のカレンダーが表示され、前月・翌月へ移動できる
- [ ] 各日付に営業日区分・会期中のアンケート件数・アサイン済み人数が表示され、月セル内に個別のアンケートが列挙されない
- [ ] 日付を選択すると、カレンダー下部の日付詳細領域にその日の対象アンケートとアサイン状況が表示される
- [ ] 定休日として土曜・日曜・祝日をそれぞれ設定できる
- [ ] 日付を指定して個別休業日を設定でき、理由をメモとして記録できる
- [ ] 定休日にあたる日付を振替営業日として設定できる
- [ ] 同一の日付に個別休業日と振替営業日を重複して設定しようとした場合にエラーが表示される
- [ ] 定休日・祝日にあたる日付に個別設定がある場合、個別設定の内容が営業日区分として表示される
- [ ] 設定を削除する際に確認ダイアログが表示される
- [ ] 日付詳細領域に、その日に会期を持つアンケートがアンケート ID・タイトル・納期日時とともに一覧表示され、件数が多い場合は縦スクロールで全件を確認できる
- [ ] 日付詳細領域から名刺入力一覧・照合管理一覧へ遷移でき、選択中の日付と対象アンケートが引き継がれる
- [ ] 日付とオペレーターの組み合わせでアサインでき、アサインを取り消せる
- [ ] アサイン画面に、その日の案件量とアサイン済み人数が並べて表示される
- [ ] Lv2 でログインした場合、営業日設定の操作要素が表示されず、設定内容は参照できる
- [ ] Lv2 でログインした場合、他グループのアンケートとオペレーターが表示されない
- [ ] Lv1 でログインした場合、本画面の URL へ直接アクセスしても表示されない

## 11. 画面外の確認事項

| # | 項目 | 内容 |
| --- | --- | --- |
| 1 | 既存案件への遡及反映 | 営業日設定の変更を、既に納期が確定している案件へ自動反映するかを確定する。反映する場合、納期が前倒しになる案件の扱いを決める。 |
| 2 | 祝日の取得方法 | 祝日を外部 API から取得するか、CSV インポートまたは手動登録で管理するかを確定する。 |
| 3 | 営業日設定の適用単位 | 営業日設定を全社共通とするか、グループ単位で持てるようにするかを確定する。Lv2 が自グループのみを扱う前提と整合させる。 |
| 4 | アサインの単位 | アサインを日付単位とするか、作業グループ①〜⑧単位またはアンケート単位まで指定するかを確定する。 |
| 5 | キャパシティの算出根拠 | 案件量に対する必要人数の目安をどう算出するかを確定する。1 人あたりの処理可能件数を基準値として持つかを含む。 |
| 6 | CSV インポートの形式 | §4.6 を導入する場合、取り込む列構成と重複時の扱いを確定する。CSV の仕様は 2026-05-12 に決定済みであり、追加要件から必須要件へ移す余地がある。 |
| 7 | アサインの取り消し通知 | アサインを取り消した際に、対象のオペレーターへ通知を送るかを確定する。 |
| 8 | 過去日付の編集 | 過去の日付に対する営業日設定の変更を許可するかを確定する。 |
| 9 | アサイン結果の反映方式 | §7.3 のアサイン結果を名刺入力一覧（SCR-A-009）へどう反映するかを確定する。出題対象を制約するか、進捗把握のための記録に留めるかを決める。`19_admin_data_input_list.md` §11 の #1・#9 と同一の論点である。 |
| 10 | Lv2 への営業日設定の参照可否 | §6 の「Lv2 は営業日設定を参照できる」を正式な要件とするかを確定する。たたき台に対応する記載がないため、本書で補完した規定である。 |
| 11 | 顧客データのグループ割り当て基準 | 本画面が Lv2 へ表示するアンケートの範囲は、顧客側データをオペレーターのグループへ割り当てる基準に依存する。基準は `00_admin_common_permissions.md` §10 の #10 で確定する。 |
| 12 | 営業日設定の競合規則 | §4.3 の優先順位（個別設定を定休日・祝日より優先する）と、個別休業日と振替営業日の重複禁止を正式な要件として確定する。定休日にあたらない日付へ振替営業日を設定できるかを併せて決める。 |
| 13 | 月セルと日付詳細の表示方式 | §4.2 の月セルをアンケート件数のみの表示とするか、上限件数までアンケート ID を並べて超過分を省略表記とするかを確定する。あわせて §4.4 の日付詳細領域の位置（カレンダー下部）と、1 画面に収める件数の目安を決める。 |
