## 1. 文書目的

- 本書は、管理者画面のダッシュボードの要件を定義する。本画面は新設である。
- 全画面に共通する権限、UI 規則、監査ログ、通知、用語は共通編を参照する。本書は本画面に固有の要件を扱う。
- 各指標の詳細な確認・操作は遷移先の画面で行う。遷移先の要件は各画面のファイルで扱う。

## 2. 画面概要

- ログイン直後に表示し、その日に対応すべきことを数値で把握するための集計画面。
- 表示した数値から、対応が必要な画面へ直接遷移できるハブとして機能する。
- 表示する範囲はログイン中アカウントの担当範囲に限定する。権限レベルによって表示する指標の集合が変わる（§6）。
- 表示は数値カードと表で構成する。

## 3. 想定利用者と対象範囲

### 3.1 想定利用者

- 運営全体を管理する Lv3・Lv4。顧客の増加、案件の発生、データ化の申込状況を横断で確認する。
- 作業を管理する Lv2（OperatorAdmin）。自グループの作業状況と遅れの有無を確認する。
- 入力作業を行う Lv1（Operator）。自分の作業状況を確認する。

### 3.2 対象範囲

- 運用状況の集計値の表示
- 新規ユーザー、新規アンケート、名刺データ化申込状況の表示
- 集計値からの各画面への遷移

### 3.3 対象外

- 集計値の元となるデータの編集・操作（各画面で行う）
- オペレーター別の実績集計（`24_admin_achievements.md`）
- 通知の一覧表示

## 4. 画面要件

### 4.1 共通構成

- ヘッダー、サイドバー、パンくずを表示する（`01_admin_common_ui.md` §2）。
- 画面タイトルを表示する。
- 画面は上から、運用状況サマリ、現在会期中のアンケート一覧、新規発生の状況、名刺データ化申込状況の順に配置する。
- 各領域の集計対象期間と最終更新日時を表示する。

### 4.2 運用状況サマリ

対応が必要な件数を数値カードとして表示する。掲載する指標は「見て当日の行動が変わる」「この画面でしか分からない」「日々変わる」の 3 点を満たすものを選ぶ。次の指標は暫定案であり、指標集合と各指標の集計定義は §11 の #1・#2 で確定する。

表示する指標の集合は Lv3・Lv4 を全体像とし、権限レベルに応じてそこから削る（§6）。遷移先の画面にアクセスできない権限レベルでは、その指標を表示しない。カードは下位の権限レベルでも残る指標を先に並べ、権限が下がるにつれて後方から欠ける配置とする。

| 指標 | 内容 | 遷移先 | 表示する下限 |
| --- | --- | --- | --- |
| 入力待ちの名刺件数 | 入力が完了していない名刺の件数 | データ入力対象一覧（SCR-A-009） | Lv2 |
| 入力進捗率 | 入力済みの名刺件数を総件数で除した割合。分子と分母も併記する | データ入力対象一覧（SCR-A-009） | Lv1 |
| 滞留している作業グループ | 進捗が低く作業が溜まっている作業グループの件数。判定は `19_admin_data_input_list.md` §4.3 に従う | データ入力対象一覧（SCR-A-009） | Lv1 |
| 照合待ちのアンケート数 | 照合が完了していないアンケートの件数。照合結果一覧（SCR-A-011 / SCR-A-012）§4.2 の「進行中の作業対象アンケート数」と同じ数を指す。両画面で違う数を出さない | 照合結果一覧（SCR-A-011 / SCR-A-012） | Lv2 |
| 納期を過ぎたアンケート数 | 納期日時を過ぎても照合が完了していないアンケートの件数 | 照合結果一覧（SCR-A-011 / SCR-A-012。納期超過で絞り込む） | Lv2 |
| 本日が納期のアンケート数 | 納期日時が当日のアンケートの件数。対象の日付を併記する | 照合結果一覧（SCR-A-011 / SCR-A-012） | Lv2 |
| 招待・本登録未了のユーザー数 | 招待中および本登録未了のユーザーの件数。招待期限切れ間近の扱い（滞留判定の基準）は §11 の #4 で確定する | ユーザー管理（SCR-A-002。アカウント状態「招待中」で絞り込む） | Lv3 |

納期に関する 2 指標は、運用で最初に確認する数字であるため運用状況サマリへ置く。照合結果一覧（SCR-A-011 / SCR-A-012）は納期日時を既定の並び順とし納期超過を識別表示するが、そこへ入るまで気付けない状態だった（2026-08-09 の判断）。

「会期中のアンケート数」はカードとして持たない。§4.2a の一覧を直下に置いており、同じ数を件数表示で示すため重複する（2026-08-09 の判断）。

Lv1 では「入力待ちの名刺件数」に代えて「あなたが着手できる名刺件数」を表示する。同一のカードのデータ範囲が本人の着手可能分に絞られたものとして扱い、指標名もその範囲を表す表記とする（§4.5）。

- 各カードには指標名と数値を表示する。数値は 3 桁ごとのカンマ区切りとする（`01_admin_common_ui.md` §9）。
- カードを押下すると遷移先の画面へ移動する。遷移時は当該指標に対応する絞り込み条件を適用した状態で表示する（`01_admin_common_ui.md` §4.1.1）。
- 対応が不要な状態（0 件）のカードも表示し、数値に 0 を表示する。
- 権限レベルによってカードの枚数が変わるため、カードの横幅には上限を設ける。枚数が少ない権限レベルでカードが引き伸ばされない配置とする。

各指標の集計定義（対象期間、カウント条件、基準値）は §11 で確定する。

### 4.2a 現在会期中のアンケート一覧

- 会期中のアンケートを表形式で全件表示する。本画面の中心となる一覧であり、残り時間や期日超過などの切迫度の演出は置かず、事実列のみで構成する。
- 表示項目: アンケートID、タイトル、契約ユーザー、会期（開始日〜終了日）、回答数、納期区分。
- 行を押下するとアンケート詳細（SCR-A-005）へ遷移する。
- 回答数は会期前のテスト回答を含む累計とする（アンケート管理の一覧と同じ集計）。

### 4.3 新規発生の状況

| 指標 | 内容 | 遷移先 |
| --- | --- | --- |
| 新規ユーザー数 | 対象期間中に登録されたユーザーの件数 | ユーザー管理（SCR-A-002） |
| 新規アンケート数 | 対象期間中に作成されたアンケートの件数 | アンケート管理（SCR-A-004） |

- 数値カードとして表示し、押下で遷移先へ移動する。
- 対象期間は画面上に明示する。「新規」の判定基準は §11 で確定する。

### 4.4 名刺データ化申込状況

- 名刺データ化の申込があるアンケートについて、申込件数とデータ化対象の名刺件数を表示する。
- 集計期間を画面に明示する。§4.2 の入力進捗率が進行中の対象だけを見るのに対し、本節は全期間の累計であり、同じ「データ化対象の名刺」でも数が一致しない。
- 申込プランの区分ごとに件数を表示する。区分は納期区分（オンデマンド、超特急、特急、通常、お試し）とする（`04_admin_common_glossary.md` §4）。
- 表形式で表示し、区分ごとの行からアンケート管理（SCR-A-004）へ遷移する。遷移時は押下した納期区分で絞り込んだ状態で表示する（`01_admin_common_ui.md` §4.1.1）。

### 4.5 Lv1 の表示

Lv1 でログインした場合も §4.2 と同じ数値カードの構成とし、Lv1 がアクセスできる画面に対応する指標だけを残す。Lv1 専用の別レイアウトは設けない。

| 指標 | 内容 | 遷移先 |
| --- | --- | --- |
| あなたが着手できる名刺件数 | 現在着手できる名刺の件数。「入力待ちの名刺件数」のデータ範囲を本人の着手可能分に絞ったもの | データ入力対象一覧（SCR-A-009） |
| 入力進捗率 | 入力済みの名刺件数を総件数で除した割合 | データ入力対象一覧（SCR-A-009） |
| 滞留している作業グループ | 進捗が低く作業が溜まっている作業グループの件数 | データ入力対象一覧（SCR-A-009） |

- カードの下に入力を開始する操作を配置し、名刺入力画面（SCR-A-010）へ遷移する。
- 一覧（§4.2a）は遷移先の画面にアクセスできないため表示しない。

自分の入力件数・正答率を表示するかは、オペレーター実績確認（SCR-A-015）の Lv1 閲覧可否と連動する。確定は `00_admin_common_permissions.md` §10 の #7 および §11 の #6 に従う。

## 5. 通知

本画面の操作を起点とする通知・メールの発火はない（`03_admin_common_notifications.md` §2）。

## 6. 権限とデータ範囲

| 権限レベル | 扱い |
| --- | --- |
| Lv1 | 自グループの範囲。表示するのは §4.5 の自分の作業状況のみ |
| Lv2 | 自グループのデータのみを集計対象とする。表示する指標は下表のとおりとする |
| Lv3 | 全グループのデータを集計対象とする。§4.2〜§4.4 のすべてを表示する |
| Lv4 | 全グループのデータを集計対象とする。§4.2〜§4.4 のすべてを表示する |

Lv2 に表示する指標を項目単位で次に定める。

| 指標 | 出典 | Lv2 |
| --- | --- | --- |
| 入力待ちの名刺件数 | §4.2 | 表示する |
| 入力進捗率 | §4.2 | 表示する |
| 滞留している作業グループ | §4.2 | 表示する |
| 照合待ちのアンケート数 | §4.2 | 表示する |
| 納期を過ぎたアンケート数 | §4.2 | 表示する |
| 本日が納期のアンケート数 | §4.2 | 表示する |
| 招待・本登録未了のユーザー数 | §4.2 | 表示しない |
| 現在会期中のアンケート一覧 | §4.2a | 表示しない |
| 新規ユーザー数 | §4.3 | 表示しない |
| 新規アンケート数 | §4.3 | 表示しない |
| 名刺データ化申込状況 | §4.4 | 表示しない |

- 権限判定とデータ範囲の絞り込みはサーバー側で行う（`00_admin_common_permissions.md` §9.1）。
- 表示しない指標は、顧客情報・金銭情報を扱うもの、または遷移先がユーザー管理（SCR-A-002）・アンケート管理（SCR-A-004）・請求管理（SCR-A-006）であり Lv2 がアクセスできないものである。
- 遷移先の画面にアクセスできない権限レベルでは、対応する指標のカードを表示しない。
- Lv2 に表示する指標の最終確定は §11 の #7 で扱う。

## 7. 状態と挙動

### 7.1 初期表示

- ログイン後の遷移先を本画面とする。
- 表示時点の集計値を取得して表示する。

### 7.2 集計値の反映

- 集計値は最大 5 分の反映遅延を許容する（`05_admin_nonfunctional.md` §2）。
- 画面には集計の最終更新日時を表示する。

### 7.3 遷移

- 指標から遷移した先の画面では、当該指標に対応する絞り込み条件を適用した状態で一覧を表示する。
- 遷移先で条件を変更した場合、本画面へ戻った際の集計値は再取得した値とする。

## 8. 現行画面からの引き継ぎ

現行画面 `/admin/top` はメニュー 10 項目のリンク集であり、集計表示を持たない。本画面は新設として全機能を新たに実装する。

参考: 現行モック `03_admin/index.html` は、運用状況サマリのカード（Lv 別の出し分け込み）、会期中アンケート一覧、新規発生の状況、名刺データ化申込状況まで本書の §4.2〜§4.4 に沿って実装済み（2026-08-12 時点）。モックは仕様上の正解とは扱わない。

## 10. 画面確認観点

モックアップ上で次を確認する。

- [ ] ログイン後に本画面が表示される
- [ ] §4.2 の各指標が数値カードとして表示される
- [ ] 各指標カードから、対応する絞り込み条件を引き継いだ状態で遷移先画面へ遷移する
- [ ] 現在会期中のアンケート一覧が表示され、行押下で当該アンケートのアンケート詳細へ遷移する
- [ ] 新規ユーザー数・新規アンケート数が対象期間とともに表示される
- [ ] 名刺データ化申込状況が納期区分ごとに表示され、行押下で当該納期区分に絞り込んだアンケート管理へ遷移する
- [ ] Lv1 でログインした場合、§4.5 の 2 指標と入力開始の操作のみが表示され、一覧は表示されない
- [ ] Lv2 でログインした場合、§6 に定める非表示の指標が表示されない
- [ ] いずれの権限レベルでもカードが引き伸ばされず、横幅が一定に保たれる
- [ ] Lv2 でログインした場合、他グループのデータが集計値に含まれない
- [ ] 集計の最終更新日時が表示される
- [ ] 対応が不要な状態（0 件）のカードにも 0 が表示される

集計値は最大 5 分の遅延を許容するため（§7.2）、遷移先の一覧件数と本画面の数値との一致は確認観点に含めない。

## 11. 画面外の確認事項

| # | 項目 | 内容 |
| --- | --- | --- |
| 1 | 表示指標の確定 | §4.2 の指標集合を確定する。運用上「今日対応すべきこと」に該当する指標が他にあるかを併せて確認する。 |
| 2 | 集計の対象期間 | 各指標の対象期間を確定する。当日、直近 7 日、当月のいずれを既定とするか、画面上で切り替えられるようにするかを決める。 |
| 3 | 「新規」の判定基準 | 新規ユーザー・新規アンケートの判定を、登録日時ベースとするか本登録完了ベースとするかを確定する。 |
| 4 | 招待・本登録未了の滞留判定 | 招待・本登録未了のユーザー数について、招待期限（72 時間）切れ間近をどう扱うか（強調表示や内数表示の要否と基準）を確定する。 |
| 5 | 「稼働中」の定義 | 稼働中のオペレーター数を、アカウント状態が有効の人数とするか、営業日カレンダー（SCR-A-008）でその日にアサインされた人数とするかを確定する。 |
| 6 | Lv1 の表示項目 | Lv1 に表示する自分の作業状況の項目を確定する。実績（正答率など）を含めるかはオペレーター実績確認の Lv1 閲覧可否と連動する。 |
| 7 | Lv2 の表示指標 | Lv2 に表示する指標の集合を確定する。顧客情報・金銭情報を除いた範囲で、作業管理に必要な指標を決める。 |
| 8 | 集計の更新間隔 | 集計値の再計算タイミングを確定する。5 分の遅延許容と整合させる。 |
| 9 | 遷移先の絞り込み条件の受け口 | 各指標の遷移先画面に、対応する絞り込み条件の受け口が未整備である（納期条件など）。指標を確定する際に、遷移先画面の絞り込み条件とセットで確定する。 |
| 10 | 入力待ち・照合待ちの定義 | 入力待ちを名刺件数、照合待ちをアンケート件数とする粒度の違いが運用上妥当かを確認する。 |
