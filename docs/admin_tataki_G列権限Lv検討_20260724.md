**前提**

- G列は「その画面を見れる権限Lv ＋ データ範囲（自グループ／全範囲）」を表す列として検討する（操作単位の権限差は対象外＝論点6）
- Lv↔ロール対応は暫定: Lv1=Operator／Lv2=OperatorAdmin／Lv3=Admin／Lv4=MasterAdmin（正式名はI列要確定のまま）
- 判断欄の記入: 採用／不採用／保留 ＋ひとこと（空欄はすべてユーザー記入待ち）
