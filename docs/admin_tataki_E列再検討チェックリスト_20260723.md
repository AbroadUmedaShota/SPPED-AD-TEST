# 管理画面たたき台 E列（最低限必要な機能）再検討チェックリスト

作成: 2026-07-23 ／ 対象: スプシ「管理画面_たたき台」全17画面
前提: B列（画面方針・粗め 7/21）・C列（画面方針メモ 7/23埋め直し）確定後の突合。E列は書き直しOK・全画面一括で判断する方針で合意済み。

**種別の凡例**
- 漏れ: 方針（B/C）にあるのに E列に無い
- 根拠なし: E列にあるが方針に根拠が無い（方針側の書き漏れ or 過剰機能）
- 昇格: H列（検討中の機能）→ E列 への昇格候補
- 保留: I列（要確定事項）の決着に依存
- 整理: 画面間の重複・表記の不一致

**判断欄の記入**: 採用 ／ 不採用 ／ 保留 ＋ひとこと（空欄はすべてユーザー記入待ち）

## 軽微・維持推奨（異議があれば番号で指摘、なければこのまま）

- a. ダッシュボードE「全社・全案件の〜」と「自分の担当範囲だけ」の同居 → Lv3-4視点/Lv1-2視点の書き分けを一言補うのみ
- b. 請求ステータス「請求済」と「入金待ち」の定義差が未定義 → 用語定義（用語集側）へ送る
- c. ユーザー管理E「メール不達・重複アカウントの検知」→ C根拠あり・維持
- d. 照合管理一覧の画面ID「SCR-A-011/012」の2ID割当 → 現状維持（旧2画面統合の経緯として）。気になるなら統合後どちらかへ寄せる
- e. クーポンの発行用途（値引き営業用/キャンペーン用等）は引き続き未決着 → 回答が来たらB/Cへ加筆（従来からの持ち越し）
