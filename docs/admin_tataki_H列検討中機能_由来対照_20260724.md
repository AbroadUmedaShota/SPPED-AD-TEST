# 管理画面たたき台 H列（検討中の機能）・通知列の整理記録

作成: 2026-07-24 ／ 2026-07-24 後半にユーザー指示「記載すべきものを再度整理」で全面監査・シート反映済み

**監査基準**: シートに記載してよいのは「B/C/D列（方針・課題）に遡れる」「ユーザー決定（AD-09等）に遡れる」「実機の実装実態に遡れる」のいずれか。根拠が過去の派生レイヤー（旧E列・通知列の種＝過去セッションのClaude起草物）にしかないものはシートから下ろし本表へ退避。

| 画面 | 項目 | 根拠 |
