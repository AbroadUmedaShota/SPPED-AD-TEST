# 管理画面たたき台 C列起点・必要最低限機能の洗い出し

作成: 2026-07-23 ／ 対象: スプシ「管理画面_たたき台」全16画面
反映: 2026-07-23 E列（E2:E17）へ書き込み済み（検討扱い項目はシート未反映）
追記反映: 2026-07-24 ユーザー指示「？付きは考慮不要（そのまま追記してよい）」により、検討扱い項目を各画面のE列末尾へ追記済み（エスカレーションのみ凍結のため除外）。操作ログの保持期間【要検討】はI列へ転記済み

**前提**
- 根拠は C列（画面方針メモ）のみ。既存E列・B列・D列・H列の内容は持ち込まない
- C列の「？」付き・「〜があっても良い」等の任意表現・画面機能でないシステム挙動の記述は、最低限機能に含めず各画面の「検討扱い」に分離
- 文言はC列の語彙をそのまま使用。採否の最終判断はユーザー

## ダッシュボード（SCR-A-001）

- 運用状況サマリの表示（集計中心・KPIカード）
- 新規ユーザー・新規アンケート・名刺データ化申込状況の表示
- KPIカード・サイドバーから対応が必要な画面への遷移
- 表示範囲を自分の担当範囲に限定（Lv2は自グループのみ）

## ユーザー管理（SCR-A-002）

- 利用者アカウントの一覧表示
- ユーザーID・会社名・氏名・メールアドレスでの検索
- アカウント情報の編集
- 本登録未了アカウントの識別表示
- プレミアム関連の確認・変更
- アカウントの停止
- 該当ユーザーのアンケート一覧・請求情報への遷移

検討扱い: ユーザー招待（C列で【検討中新機能】表記のため）

## ユーザー詳細（SCR-A-003）【検討中画面】

- 利用者アカウントの個別詳細表示
- アカウント情報の変更
- パスワード変更・再発行（管理者代行、ユーザー側でできない操作）
- メール（招待・パスワード変更等）の本人到達確認
- 紐づくアンケート・請求状況のまとめ確認

## アンケート管理（SCR-A-004）

- アンケートの一覧・確認
- アンケートID・ユーザーID・会社名・氏名・作業ステータスでの検索
- アンケートの作成・編集・削除（会期前〜会期中）
- 利用者側で制限がかかっている操作の実行（当日中のアンケート編集等）
- 当日会期・新着（前日比増）アンケートの確認
- 名刺データ化されたデータの確認・公開（会期後）
- アンケートに関連するデータのダウンロード（通期）
- トラブル時の強制停止
- 完了データの手動アップロード（不具合時の取込用）
- データ化申込プランの確認
- 該当アンケートの請求情報・アカウント情報への遷移

検討扱い: お礼メールの内容確認（C列で「とかも？」表記のため）
前提注記: 「照合が終わったデータは自動で完成データになる」は画面機能でなくシステム挙動のため機能一覧から除外（開発側へ現状開示要求中の項目）

## アンケート詳細（SCR-A-005）【検討中画面】

- 対象アンケートの全設定の確認・設定・変更
- 利用者側で制限がかかっている操作の実行（運営代行）
- 個別回答の削除（名刺データの削除依頼対応）
- 公開後のアンケート変更（通常の編集と分離した危険操作として）
- データ化申込プランの確認

## 請求管理（SCR-A-006）

- 全顧客の請求情報・入金状況の一覧確認
- 未入金案件の識別表示
- 入金状況の変更
- ユーザーID・会社名・請求ステータスでの検索
- クーポン割引の事後適用（当月内）

## クーポン管理（SCR-A-007）

- クーポンの作成・編集
- 使用可能期限・割引率・使用可能回数の設定
- 使用率の確認（どこで使われたか）
- 利用履歴の確認（どのアンケートでいつ使われたか）

## 営業日カレンダー管理（SCR-A-008）

- 休業日・振替営業日の設定変更
- 案件量と人員を見比べたキャパ調整・作業アサイン（Lv2の運用）
- Lv1には表示しない（アクセス制御）

検討扱い: 祝日・稼働可能日等のCSVインポート（C列で「？」表記のため）

## 名刺入力一覧（SCR-A-009）

- 入力画面への遷移（作業開始の入口）
- 作業可能件数の表示（アカウントごと）
- グループ①〜⑧単位の進捗・件数の可視化

検討扱い: 全体件数の表示範囲（C列で「Lv2以上？」表記）／Lv2以上向けグループ一括入力画面への導線（「あっても良い」表記）／多言語名刺の言語選択入力（【検討中】表記）

## 入力個票・入力画面（SCR-A-010）

- 名刺画像を見ながらの項目入力
- キーボード完結の操作体系（マウス操作も可）
- 優先順位に従った出題（納期順: プレミアム＞超特急＞特急＞通常、同順位内は回答順）
- 3回入力不成立・要判断名刺のエスカレーション登録（フラグで別画面へ）
- 名刺画像の操作（拡大・縮小・回転）

検討扱い: OCR・他オペレーター入力内容の表示とクリックコピー（「？」表記）／入力項目の補完情報表示（「など」の曖昧表記）／QRコード・バーコード等の特殊入力（「については？」表記）

## 照合管理一覧（SCR-A-011/012）

- 照合画面への遷移（作業開始の入口）
- 一覧表示（アンケートID／タイトル／会期／総件数／未入力／一致／不一致／納期日時）
- アンケートごとの照合進捗の確認
- アンケートID・ユーザーID・作業ステータス（会期前・会期中・データ化中・データ化完了）での検索・並び替え
- 任意の名刺を指定した照合の開始
- 完成データ・全レコードのダウンロード

## 照合個票・照合画面（SCR-A-013）

- 名刺の表裏画像を見ながらの照合
- 項目ごとの並列表示（OCR結果／DB／入力1〜3／修正入力／完成内容）
- 一致項目・不一致項目の識別表示
- 不一致項目への修正入力（照合者による正しい値の入力）
- 候補値のクリック選択による入力欄への反映
- 名刺画像の操作（拡大・縮小・回転）

## エスカレーション（SCR-A-016）※凍結

> 2026-07-23 ユーザー回答: 画面名の「凍結」は検討自体の凍結の意。本画面は当面検討対象外（F列も記入しない）。以下は凍結解除時の参考として残置。

- イレギュラー発生名刺の名刺画像単位での確認
- 名刺画像の操作（拡大・縮小・回転）

検討扱い: エスカレ理由の表示・入力（「？」表記）／エスカレボタン押下時点の状態引き継ぎ表示（「？」表記）

## オペレーター管理（SCR-A-014）

- 全オペレーターの一覧確認
- オペレーターの登録・編集（登録メールアドレス・登録名等）・削除
- 所属・権限レベル・対応言語・有効/無効の設定
- パスワードの変更・再発行
- オペレーターの招待（実行はLv2まで）
- グループの作成（Lv3以降）
- アクセス制御（Lv1は参照不可／Lv2は自グループ内のアカウントのみ設定可）

## 実績管理（SCR-A-015）

- オペレーター別実績の確認・集計（入力項目ごとの作業件数／正解件数／正答率／報酬金額／スキップ回数）
- グループ別・オペレーター別・チーム単位での集計表示
- 月単位での確認
- CSV出力

## 操作ログ・監査ログ（SCR未採番）

- 運営側操作の履歴確認（誰が・いつ・何を。対象: 代行変更／パスワード直接設定／権限Lv変更／有効・無効化／招待／回答・アンケートの削除／公開後の設問変更／完了データの手動アップロード／CSV・名刺画像等の持ち出し／ログイン・ログアウト等）
- ログの編集・削除の禁止（追記のみ）
- ログのファイル出力

検討扱い: 変更前→変更後の値・入力された理由・成功/失敗の記録（「べき？」表記）
要確定へ転記候補: ログをどこまで・いつまで残すか（C列に【要検討】表記のまま）

## 洗い出し中に気になった点（C列側への確認・追記候補）

1. ~~エスカレーション画面のC列が薄い~~ → **決着（2026-07-23）**: 画面ごと凍結（検討対象外）のため追記不要
2. **ユーザー詳細のメール到達確認**: D列に「正しく実装できないとの報告あり」があるため、このまま最低限機能に置くかは判断が必要
3. **「招待はlv2まで」の解釈**: 「Lv2以上の権限者が実行できる」の意か「招待で作れるのはLv2まで」の意か、二通りに読める
4. **オペレーターの「削除」**: AD-09の決着（退職者も「無効」運用・論理削除は内部フラグ）と表現が揃っていない。「削除」を残すか「無効化」に寄せるか
5. **実績管理の「報酬金額」**: I列の要確定「報酬額・評価指標を含めるか」が未決着のまま、C列では確定調になっている
