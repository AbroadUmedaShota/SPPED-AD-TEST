# 管理画面たたき台 E列 マスト／あったほうが良い 区分

作成: 2026-07-24 ／ 対象: スプシ「管理画面_たたき台」E列（E2:E17・全16画面）
反映: 2026-07-24 シート書き込み済み（セル内を上段=マスト・下段=【あったほうが良い】ブロックに再構成。項目の削除なし）

## 判定基準（全画面共通）

1. C列（画面方針メモ）の表現強度: 「必要がある」「したい」→マスト／「と良い」「あっても良い」「？」「【検討中】」→あったほうが良い
2. 現行画面（F列）に既にある機能はマスト（現行運用の置き換え最低線）
3. その画面の目的（B列）が成立しなくなる機能はマスト
4. 要確定事項（I列）が未決着のものはあったほうが良い側で待機

## 区分結果

全項目マストのため変更なし（6画面）: ダッシュボード／アンケート詳細／請求管理／照合管理一覧／オペレーター管理／エスカレーション（凍結のため対象外）

## 境界判断（マスト昇格の余地があるもの）

1. 営業日カレンダーのCSVインポート: 2026-05-12の要件立て直しでCSV仕様自体は決定済み。決定を重く見るならマスト昇格
2. クーポンの使用率確認: B列の「発行から効果確認までを一画面で完結」を画面の目的として重く見るならマスト昇格
3. 実績管理の報酬金額: 現行画面には表示が既にある。I列要確定が「含める」で決着すればマストへ戻す
4. アンケート管理の当日会期確認: 新着（前日比増）と別に、当日会期分だけマストへ残す切り方もある
