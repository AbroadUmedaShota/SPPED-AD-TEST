SPEED AD 個人情報保護方針

SPEED AD（以下、「当サービス」といいます。）は、お客様の個人情報の重要性を認識し、その保護に努めます。当サービスは、個人情報の取扱いに関し、「個人情報の保護に関する法律」および関連する法令、ガイドライン等を遵守します。

1. 個人情報の取得

当サービスは、適法かつ公正な手段によって、お客様の個人情報を取得します。主には、会員登録、お問い合わせ、サービスの利用時に、氏名、メールアドレス、会社名などの情報を提供いただきます。

2. 個人情報の利用目的

当サービスが取得した個人情報は、以下の目的で利用します。

  • 当サービスの提供、運営、改善のため
  • お客様からのお問い合わせに対応するため
  • 当サービスの新しい機能、更新情報、キャンペーン等の案内メールを送付するため
  • メンテナンス、重要なお知らせなど必要に応じたご連絡のため
  • 利用規約に違反したユーザーや、不正・不当な目的でサービスを利用しようとするユーザーの特定をし、ご利用をお断りするため

3. 個人情報の第三者提供

当サービスは、以下の場合を除き、あらかじめお客様の同意を得ることなく、第三者に個人情報を提供することはありません。

  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
  • 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき
  • 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合

4. お問い合わせフォームで利用する外部サービス

お問い合わせフォームでは、不正な自動投稿の防止とお問い合わせ対応のため、以下の外部サービスを利用します。

  • Cloudflare Turnstile: 自動投稿防止のため、送信時の確認トークンを検証します。氏名、メールアドレス、件名、本文、添付ファイルはCloudflare Turnstileへ送信しません。
  • Google Workspace: お問い合わせ内容、添付ファイル、受付メールを保存・送信し、対応履歴の管理と回答に利用します。

お問い合わせ確認アプリのGmailデータ

公開前の確認用草案

アブロードアウトソーシング株式会社が運営するSPEED AD お問い合わせメール確認アプリは、お問い合わせ対応のため、公式窓口 customer@speed-ad.com の所有者の読取専用許可に基づいてGmailデータを取得・処理します。

取得する情報と閲覧できる人

受付データから決まる対象期間の送受信メールを、迷惑メール・ゴミ箱も含めて同期し、通常の同期では下書きを除きます。メールの件名、送受信者、日時、本文、添付情報を取得・処理して案件との関連を照合し、判断できないメールは照合待ちとして表示します。

同期・再照合の事前判定は実装・検証中です。同期・再照合の対象判定では、対象期間外・下書きを含む候補メールのID・ラベル・内部日時だけを先に一時取得する構成を準備しています。件名・宛先・本文・添付を取得するのは、対象期間内で下書きではない候補だけとします。この取得制御の実装と検証が完了したことを公開前に確認します。

アプリの認証を通った @abroad-o.com の社員全員と公式窓口の利用者が、案件に関連するメールと照合待ちのメールの本文・添付、確認記録を閲覧できます。この人による閲覧範囲を窓口所有者へ説明し、明示的な同意を得ます。要求するGmail権限は読取専用で、メールの送信・変更・削除を行いません。

保存する情報と期間

Google CloudのFirestoreに、件名、送受信者、日時、メール・スレッドの識別情報、添付ファイル名などの添付情報、案件との関連、最初の確認者と日時、同期位置、監査・処理記録を保存します。本文は同期時の照合と閲覧時にGmailから取得します。Gmailのメール取得応答に添付データが含まれる場合、その添付データも同期時に一時受信します。メール取得応答に添付IDだけがあるファイル本体は、閲覧時にそのIDを指定して別途取得します。本文・添付ファイル本体はサーバーの一時メモリと利用者画面で処理し、Firestoreへ保存しません。

継続読取り用の資格情報と、同意した説明全文・説明版・照合用のhash・同意日時・確認済み窓口の記録をSecret Managerに保存します。照合待ちの記録は、案件との照合または除外の判断が確定するまで保持します。案件に結び付いたメール照合・確認記録は案件終了から3年、除外したメールの記録は除外確定から3年を保存期限とし、管理者が期限を確認して手動で削除します。自動期限削除は行いません。Gmail原本の保存・削除は別に管理します。

削除済みのメール記録が再び取り込まれることを防ぐため、Gmail原本がある間は、現在の同期対象期間外でもメールIDから作る最小の照合用の値（hash）を保持します。元のメールID、件名、宛先、確認者はこの最小記録に保存しません。

削除済み案件の再処理と旧操作要求の再実行を防ぐため、案件IDと操作要求IDから作るhashも保持します。これらのhashの保存期間と削除条件は確認待ちです。公開前に確定し、この説明へ反映します。

再取込防止記録の整理

管理者が再取込防止記録を整理する際は、原本がないことと列挙の完全性を確認するため、同期対象期間外・下書き・迷惑メール・ゴミ箱を含むGmail全体のメールIDを列挙します。重複検査用のhash集合をFirestoreに一時保存し、整理の完了または取消し時に削除します。この整理で同期対象期間外のメール本文・添付ファイル本体は取得しません。

連携の停止と削除依頼

窓口所有者はGoogleアカウントの接続管理から本アプリのアクセスを取り消せます。取消し後も保存済みの記録は自動では消えません。メール照合・確認記録の削除依頼は、対象の案件IDまたはメールIDを添えて s-umeda@abroad-o.com へご連絡ください。連携停止やアプリ側の記録削除でGmail原本を削除しません。

Gmailデータを広告の配信、販売、一般的なAIモデルの学習に利用しません。Google Workspaceから取得した情報は、Google API Services User Data PolicyのLimited Use要件に従って扱います。

5. 個人情報の管理

当サービスは、個人情報の紛失、破壊、改ざん及び漏えいなどを防止するため、不正アクセス、コンピュータウイルス等に対する適正な情報セキュリティ対策を講じます。

6. 個人情報の開示・訂正・削除

お客様は、当サービスが保有する自己の個人情報が誤った情報である場合には、当サービスが定める手続きにより、個人情報の訂正、追加または削除を請求することができます。当サービスは、お客様からこれらの請求を受けた場合、遅滞なく必要な調査を行い、その結果に基づき、個人情報の内容の訂正等を行い、これをお客様に通知します。

7. 個人情報保護方針の変更

当サービスは、必要に応じて、本個人情報保護方針を変更することがあります。変更後の個人情報保護方針は、当サービスが別途定める場合を除き、当ウェブサイトに掲載したときから効力を生じるものとします。
